# Git & GitHub

Everything you need to know about version control, collaboration, and CI/CD at EndToEndLabCR. Follow the reading order below for a guided progression from basics to advanced.

---

## Reading Order

### Level 1: Fundamentals

Start here if you're new to Git or joining the organization.

1. **[Git & GitHub Basics](./git-basics.md)** — what Git is, key concepts, terminology, and how the contribution flow works
2. **[Essential Commands](./github/essential-commands.md)** — quick reference for everyday Git usage
3. **[Your First Contribution](../../guides-and-tutorials/git-github-guide.md)** — step-by-step walkthrough from fork to merged PR

### Level 2: Our Workflow

Once you understand the basics, learn how we actually work.

4. **[CI/CD Pipeline Architecture](./ci-cd-pipeline.md)** — **source of truth**: our two-branch model (`dev` + `main`), fork setup, PR conventions, commit standards, CI/CD stages, deployment, and rollback
5. **[Commit Guidelines](./github/commits-guide.md)** — Conventional Commits format, writing good messages, and best practices
6. **[Branch Naming Guidelines](./github/branch/naming-guidelines.md)** — how we name branches and why

### Level 3: Standards & Quality

Deepen your understanding of our engineering standards.

7. **[Code Review Guidelines](./code-review-guidelines.md)** — PR checklist, review process, and how to give/receive feedback
8. **[Repository Naming Guidelines](./github/projects-guide.md)** — how we name repos across the organization
9. **[GitHub Actions](./github-actions.md)** — CI/CD syntax, patterns, and workflow examples
